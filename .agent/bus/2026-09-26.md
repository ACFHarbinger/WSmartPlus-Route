**Top findings:**
- **B-gemini-01:** `AttentionModelPolicy.__init__` accepts `normalization: str = "batch"` and forwards `normalization=normalization` to `GraphAttentionEncoder`. However, `GraphAttentionEncoder` expects `norm_config: Optional[NormalizationConfig]` and absorbs `normalization` into `**kwargs`. `TransformerEncoderBase` falls back to `NormalizationConfig(norm_type="batch")`, so passing `normalization='layer'` or `'instance'` silently builds `nn.BatchNorm1d`.
- **B-gemini-02:** `NeuralAgent.simulation.py:76` returns `([0], 0, {"mandatory_empty": True})` when the mandatory set is empty. Owner ruling D3 established that `[0, 0]` is the invariant empty tour across all policies.
- **B-gemini-03:** `policy_na.py:145` calculates `collected_revenue` by multiplying `bins.c` (percentage fill $[0, 100]$) directly by `revenue_kg`. Physical collection in `bins/base.py:378` evaluates `(real_c / 100) * volume * density`. Directly multiplying percent by `revenue_kg` produces non-physical revenue scale distortions.
- **B-gemini-04 / D-gemini-01:** `GlimpseDecoder` defines `self.project_fixed_context = nn.Linear(embed_dim, embed_dim, bias=False)` and precomputes `fixed.graph_context`. Neither `_get_log_p`, `_get_parallel_step_context`, nor `one_to_many_logits` ever consumes `fixed.graph_context`. These $embed\_dim^2$ parameters are completely dead and receive zero gradient. Zeroing `fixed.graph_context` produces 0.0 logit difference.
- **B-gemini-05:** `AttentionModel.context_embedder.project_step_context` is dead code because decoding delegates to `GlimpseDecoder`, forcing `loader.py` to maintain `_UNUSED_LEGACY_KEYS`.

**Paper fidelity (Kool et al. 2019 §3 & App. A):**

- **P-gemini-02:** Selection logits are projected into 8 heads and averaged, rather than using a single head with $d_k=d$.
- **P-gemini-03:** VRPP context features cleanly adapt Kool et al. PCTSP context for waste routing.
- Norm placement (post-residual), FF width 512, $\sqrt{d_k}$ glimpse scaling, and logit tanh clipping ($C=10$) are faithful to the paper.
